# Backend

Node.js + Express.js + JavaScript (ES Modules).

## Cấu trúc

```
backend/
├── src/
│   ├── config/
│   ├── controllers/
│   ├── middlewares/
│   ├── models/
│   ├── routes/
│   ├── services/
│   └── utils/
├── .env.example
└── package.json
```

## Chạy

```bash
npm install
npm run dev    # nodemon src/server.js
npm start      # node src/server.js
```
